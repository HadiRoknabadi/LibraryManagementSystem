# راهنمای جامع پروژه سیستم مدیریت کتابخانه (Library Management System)

این پروژه یک سیستم جامع مدیریت کتابخانه تحت وب است که با استفاده از معماری چندلایه و فریم‌ورک **ASP.NET Core MVC** توسعه یافته است. هدف این پروژه ساده‌سازی فرآیندهای امانت‌دهی، مدیریت کتاب‌ها، ناشران، نویسندگان و اعضای کتابخانه است.

---

## ✨ امکانات و قابلیت‌های کلیدی پروژه

### مدیریت کاربران و اعضا:
* ثبت‌نام، ورود ایمن و خروج با بهره‌گیری از **ASP.NET Core Identity**
* تخصیص کد عضویت اختصاصی برای هر کاربر
* مدیریت فعال/غیرفعال بودن حساب کاربری
* سیستم احراز هویت دومرحله‌ای یا امنیتی با کپچای فارسی (**DNTCaptcha**)

### مدیریت کتاب‌ها و موجودی:
* ثبت، ویرایش، حذف و فیلتر پیشرفته کتاب‌ها
* مدیریت دسته‌بندی‌ها (ژانرها) به صورت پویا
* سیستم مدیریت نسخه‌های فیزیکی هر کتاب (**Book Copies**) جهت ردیابی دقیق تعداد کتاب‌های موجود در مخزن

### مدیریت نویسندگان و ناشران:
* ثبت و مدیریت مشخصات نویسندگان کتاب‌ها
* مدیریت اطلاعات ناشران همکار

### مدیریت امانات و بازگشت کتاب:
* ثبت فرآیند امانت گرفتن کتاب توسط اعضا با بررسی وضعیت موجودی کتاب
* ثبت تاریخ برگشت و محاسبه وضعیت تاخیر
* تولید گزارش‌های مربوط به وضعیت امانت‌دهی

### داشبورد آماری (Dashboard):
* نمایش آمارهای کلیدی (تعداد کل کتاب‌ها، امانات فعال، کاربران عضو و غیره)
* چارت‌ها و ابزارهای گزارش‌گیری سریع مدیریتی

## 🚀 راهنمای قدم به قدم راه‌اندازی پروژه

برای راه‌اندازی پروژه روی سیستم محلی خود، مراحل زیر را به ترتیب دنبال کنید:

### ۱. پیش‌نیازها
مطمئن شوید ابزارهای زیر روی سیستم شما نصب هستند:
* **SDK نسخه .NET 8.0** یا بالاتر
* دیتابیس **SQL Server**
* محیط توسعه **Visual Studio 2022** یا **VS Code**

### ۲. تنظیم Connection String
فایل `appsettings.json` را در پروژه `WebSite.EndPoint` باز کرده و مقدار `ConnectionStrings:DefaultConnection` را متناسب با سرور SQL خود تنظیم کنید:
```json
"ConnectionStrings": {
  "DefaultConnection": "Server=YOUR_SERVER_NAME;Database=LibraryDb;Trusted_Connection=True;MultipleActiveResultSets=true;TrustServerCertificate=True"
}

۳. ایجاد دیتابیس و جدول‌ها
روش اول: استفاده از ابزار Migration (توصیه شده)

کنسول مدیریت بسته (Package Manager Console) را در ویژوال استودیو باز کنید، پروژه پیش‌فرض را روی Persistence قرار دهید و دستور زیر را اجرا کنید:

Update-Database

روش دوم: استفاده از اسکریپت آماده SQL

اگر می‌خواهید بدون درگیر شدن با فرآیند Migration و ساخت کاربر جدید، دیتابیس را به همراه اطلاعات اولیه ایجاد کنید:

فایل اسکریپت SQL موجود در پوشه پروژه (مثلاً database_backup.sql) را در SQL Server Management Studio (SSMS) باز کنید.
اسکریپت را اجرا (Execute) کنید تا دیتابیس و داده‌های اولیه ساخته شوند.
۴. اجرای پروژه
پروژه استارت‌آپ را روی WebSite.EndPoint تنظیم کرده و دکمه Run (F5) را در Visual Studio فشار دهید.

🔐 اطلاعات حساب کاربری تستی
برای ورود به پنل مدیریت و تست تمام بخش‌های سیستم، می‌توانید از اطلاعات پیش‌فرض زیر استفاده کنید:

شماره موبایل (نام کاربری): 09375882135
رمز عبور: 13822646
🧪 تست‌های پروژه
پروژه شامل دو بخش تست است:

Unit Tests (تست‌های واحد):

برای تست منطق تجاری و کلاس‌های سرویس. با دستور dotnet test در روت پروژه قابل اجراست.

E2E Tests (تست‌های یکپارچه):

برای شبیه‌سازی رفتار واقعی کاربر (مانند لاگین). این تست‌ها از طریق CustomWebApplicationFactory دیتابیس را به صورت InMemory برای تست فراخوانی می‌کنند.

برای اجرای تست‌ها می‌توانید از پنجره Test Explorer در Visual Studio استفاده کنید یا دستور زیر را در خط فرمان پوشه اصلی پروژه اجرا کنید:

dotnet test

این پروژه با استاندارد Clean Architecture توسعه یافته است.
